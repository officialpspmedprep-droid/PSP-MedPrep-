# 📘 PSP MedPrep

**PSP MedPrep** is a professional, all-in-one **MDCAT preparation app** built with Flutter for Android.  
It provides complete study resources, smart mock tests, and real-time performance tracking — all in one place.

---

## 🎯 Features

✅ **Comprehensive Subjects**
- Biology  
- Chemistry  
- Physics  
- English + Logical Reasoning  
- Combined Test Mode (All Subjects)

✅ **Study Material**
- Notes, past papers, and topic-wise PDFs  
- Clean material design with offline reading support

✅ **Mock Tests & FLPs**
- Attempt tests directly inside the app  
- Automatic question & result generation from uploaded PDFs  
- View explanations after each test  

✅ **User Experience**
- Lightweight and responsive  
- Google Fonts integrated  
- Minimal, distraction-free UI  

---

## 🧠 Technology Stack

| Component | Tool / Package |
|------------|----------------|
| Framework | Flutter (Dart SDK 3.x) |
| Storage | Shared Preferences |
| PDF Rendering | flutter_pdfview |
| Text Extraction | pdf_text |
| UI Styling | Google Fonts, Cupertino Icons |
