PSP MedPrep - Flutter MDCAT Preparation App

1. Copy all provided files into the folder structure shown.
2. Open the project in Android Studio or VS Code.
3. Run:
   flutter pub get
4. Place your real PDFs in:
   - assets/notes/
   - assets/papers/
   - assets/mock_tests/
5. Start app with:
   flutter run

The app runs fully offline. Mock Tests auto-read basic questions from PDFs using pdf_text.
